## Long Description
Orleia is a free, local-first productivity app that combines six tools into one: habits, notes, journal, tasks, documents, and an AI assistant called Noor.

**What makes Orleia different:**
- **Completely free** — no subscription, no premium tier, no credit card
- **No sign-up** — open the app and start using it immediately
- **Local-first** — all your data stays in your browser. Nothing is sent to any server.
- **AI built in** — Noor, the AI assistant, has three models (Ethos 4.7, Logos 4.5, Verse 4) for chat, image generation, and voice dictation
- **Works offline** — full functionality without internet (except AI features)
- **Privacy by design** — GDPR compliant. We literally can't see your data.
- **Multi-language** — supports 19 languages
- **Accessible** — WCAG compliant with font size controls and screen reader support
- **Dark mode** — beautiful dark theme with light mode option

**Tools included:**
- Habit tracker with streaks and analytics
- Rich text notes with markdown
- Daily journal with mood tracking
- Task manager with priorities and due dates
- Document editor
- AI assistant with image generation

**Platforms:** Web (lexisapp.xyz), Desktop (Electron for Windows, macOS, Linux), Mobile (PWA)

**Built with:** Next.js, TypeScript, Tailwind CSS, Framer Motion, Electron
